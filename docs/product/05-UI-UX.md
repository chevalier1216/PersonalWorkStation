# UI / UX

## Language

預設繁體中文。

介面文字要求：

- 簡潔
- 易懂
- 非工程術語

主導航：

- 今日
- 任務看板
- 行事曆
- AI 對話
- AI 摘要
- 歷史紀錄
- 設定

## Visual Direction

風格：

金屬鐵灰 + 液態玻璃。

Discord 官網作為基調參考。

要求：

- 深鐵灰背景
- 柔和半透明 surface
- 適度 blur
- 低對比層級
- 清晰文字
- 少量冷色 accent
- 避免純黑
- 避免純白
- 避免 neon
- 避免高對比刺眼 UI
- 動畫克制

視覺不得犧牲可讀性。

## Today Layout

首頁採塊狀模組：

- Tasks
- Calendar
- AI Chat
- Notifications
- Holiday reminder

正常：

閱讀模式。

切換「編輯版面」：

- 拖曳排序
- 顯示模組
- 隱藏模組

版面必須持久保存。

V1 不做自由 resize。

## Mobile

Desktop：

完整功能。

Mobile：

至少完整可使用：

- 今日
- Task
- Calendar
- AI Chat
- 通知

手機版不要求與 Desktop 同 layout。
